# 户晨风 AI 对话机器人

基于户晨风直播连麦文字稿训练的检索式对话机器人。

## 项目简介

本项目从收录的户晨风直播文字稿（2023-2025年）中提取对话内容，使用 TF-IDF 检索 + 关键词匹配的方式构建了一个对话机器人。机器人能够模拟户晨风的语言风格进行对话。

## 技术架构

```
huzi_bot/
├── config.py           # 配置文件
├── data_parser.py      # 数据解析模块 - 解析 Markdown 文件
├── chatbot_engine.py   # 对话引擎 - TF-IDF 检索 + 关键词匹配
├── main.py             # 主程序 - 命令行/Web 两种模式
├── requirements.txt    # Python 依赖
├── cache/              # 数据缓存目录（运行后自动生成）
└── data/               # 额外数据目录
```

## 环境要求

- Python 3.7+
- macOS（已测试）

## 快速开始

### 1. 安装依赖

```bash
cd huzi_bot
pip install -r requirements.txt
```

### 2. 运行（命令行模式）

```bash
python main.py
```

### 3. 运行（Web 网页模式）

```bash
pip install flask
python main.py --mode web
```

然后在浏览器打开 `http://127.0.0.1:8080`

## 命令说明

在命令行模式下支持以下命令：

| 命令 | 说明 |
|------|------|
| 直接输入文字 | 和户子聊天 |
| `search <关键词>` | 搜索相似语录 |
| `stats` | 查看统计信息 |
| `clear` | 清空对话历史 |
| `help` | 查看帮助 |
| `quit` / `exit` | 退出程序 |

## 工作原理

1. **数据解析**: 遍历所有 Markdown 文件，提取 `户晨风：` 和 `某网友：` 的对话
2. **语料构建**: 提取户晨风的回复作为应答语料库，同时构建问答对
3. **索引构建**: 使用 jieba 分词 + TF-IDF 向量化构建检索索引
4. **对话检索**: 用户输入后，通过余弦相似度找到最匹配的户晨风回复
5. **话题感知**: 自动检测话题（经济、教育、就业等），提升相关回复的优先级
6. **兜底策略**: 当无法匹配时，根据话题返回预设的户晨风风格回复

## 注意事项

- 首次运行需要解析所有数据文件，可能需要 1-2 分钟
- 解析结果会缓存到 `cache/` 目录，后续启动会直接使用缓存
- 本机器人仅供娱乐，回复内容不代表户晨风本人观点
- 语音转文字原文可能存在一些识别错误

## 自定义配置

编辑 `config.py` 可以调整以下参数：

- `SIMILARITY_THRESHOLD`: 相似度阈值（越低越容易匹配）
- `TFIDF_TOP_N`: 候选回复数量
- `MIN_RESPONSE_LENGTH`: 最小回复长度过滤
- `KEYWORD_BOOST`: 关键词匹配权重提升
